# Оценка качества поиска

Инструменты для воспроизводимой проверки Precision@K и сравнения семантического
поиска с подстрочным поиском по имени файла. Каталог является частью обзорной
версии коммерческого проекта и опубликован только для подтверждения опыта
автора при рассмотрении резюме. Условия использования приведены в
[LICENSE](../../../LICENSE).

## Состав

| Файл | Назначение |
|---|---|
| `generate_dataset.py` | Создаёт детерминированный набор из 50 файлов разных типов |
| `build_real_dataset.py` | Собирает смешанный набор с фотографиями Flickr8k и документами |
| `queries.json` | Запросы и ground truth для синтетического набора |
| `real_queries.json` | Запросы и ground truth для смешанного набора |
| `run_experiment.py` | Считает Precision@K и сохраняет детализацию в JSON |

## Вариант 1: регрессионный набор

```bash
cd experiment
python generate_dataset.py --out ./test_dataset
```

Будут созданы 50 файлов и `_manifest.json`. Нейтральные имена вроде
`IMG_0001.png` и `FILE_0001.pdf` не раскрывают содержимое, поэтому сценарий
проверяет именно семантический поиск, а не совпадение с названием.

Зависимости генератора: `pillow`, `pymupdf`, `python-docx`, `openpyxl`.

## Вариант 2: смешанный набор

```bash
python build_real_dataset.py --out ./real_dataset --images 20
```

Скрипт загружает фотографии Flickr8k через Hugging Face datasets-server,
создаёт документы, таблицы и текстовые файлы, затем записывает разметку в
`real_queries.json`. Для этого шага требуется интернет.

## Запуск проверки

1. Запустить backend.
2. Передать абсолютный путь к выбранному набору в `/index`.
3. Дождаться `status=completed` на `/status`.
4. Запустить расчёт метрик.

```bash
curl -X POST http://localhost:8000/index \
  -H "Content-Type: application/json" \
  -d '{"path": "/absolute/path/to/experiment/test_dataset"}'

python run_experiment.py \
  --server http://localhost:8000 \
  --dataset ./test_dataset \
  --queries ./queries.json \
  --k 5 \
  --out report.json
```

Для смешанного набора используются `./real_dataset` и `./real_queries.json`.
Индексация на CPU обычно занимает несколько минут.

## Что измеряется

`run_experiment.py` выполняет каждый запрос двумя способами:

- через `/search` с семантическим ранжированием;
- локально по подстрочному совпадению с именем файла.

Precision@K вычисляется как доля релевантных файлов среди первых K результатов.
Отчёт содержит общую сводку, разрез по точным и описательным запросам, а также
полные списки результатов по каждому запросу. JSON-формат позволяет хранить
результаты регрессионных прогонов и сравнивать изменения модели или скоринга.

## Принципы набора данных

- имена большинства файлов не описывают содержимое;
- представлены изображения, PDF, DOCX, TXT, CSV и XLSX;
- запросы включают точные названия и естественные описания;
- для каждого запроса явно задан список релевантных файлов;
- генерация синтетического набора детерминирована.

Тестовые документы содержат вымышленные данные и не включают пользовательские
или клиентские материалы.
