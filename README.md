# Intelligent File Search

Коммерческий проект для поиска документов и медиафайлов по их содержимому,
а не только по имени. Android-клиент собирает выбранные пользователем файлы,
локальный ML-сервис извлекает текст и визуальные признаки, после чего запросы
обрабатываются через два FAISS-индекса.

> Репозиторий опубликован только для технического ознакомления и подтверждения
> опыта автора при рассмотрении резюме. Это не open-source проект. Копирование,
> распространение, модификация и использование кода без письменного разрешения
> правообладателя не допускаются. Подробные условия приведены в [LICENSE](LICENSE).

## Что реализовано

- семантический поиск по изображениям, видео, PDF, DOCX, TXT, CSV и XLSX;
- OCR для изображений, сканов и встроенной графики в PDF;
- гибридное ранжирование по визуальному и текстовому сходству;
- фоновая индексация с атомарной заменой индексов;
- загрузка файлов с Android и открытие найденной серверной копии;
- автоматическое обнаружение локального сервера в Wi-Fi сети;
- работа на CPU и автоматическое использование CUDA при наличии;
- воспроизводимая оценка качества по Precision@K.

## Архитектура

```text
Android-клиент
    ├── сканирование и выбор файлов
    ├── загрузка на локальный backend
    └── поиск и открытие результата
             │ REST API
             ▼
FastAPI backend
    ├── обработчики документов и медиа
    ├── SigLIP + EasyOCR
    ├── SBERT + перевод запросов ru→en
    └── FAISS: media 768D / text 384D
```

| Компонент | Технологии |
|---|---|
| Backend | Python, FastAPI, PyTorch, SigLIP, SBERT, EasyOCR, FAISS |
| Mobile | Flutter, Dart, Android SDK |
| Оценка качества | Python, requests, Flickr8k, Precision@K |

## Состав репозитория

Рабочий код находится в `project/project/`:

```text

├── backend/      # API, обработка файлов, индексация и поиск

└── experiment/   # наборы данных и сценарии оценки качества
```

Инструкции по локальному запуску и технические детали собраны в
[README проекта](project/project/README.md). У каждого компонента есть отдельная
документация.

## Границы публичной версии

Это обзорный снимок кодовой базы, подготовленный для технического интервью.
В репозиторий не включены данные пользователей, ключи, production-конфигурация,
подписанные сборки и инфраструктура развёртывания. Backend рассчитан на запуск в
доверенной локальной сети и без дополнительной защиты не должен публиковаться в
интернете.
